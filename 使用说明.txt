一、这是什么
这是 Windows Steam 版 Kingdom Rush 6: Genesis TD 的非官方本地修改器。
分享包只包含原创工具，不包含游戏。每个人都需要自己的游戏，并在自己的电脑上安装一次。

二、电脑需要什么
1. 能正常运行原游戏的 64 位 Windows 电脑。
2. Windows PowerShell 5.1 及系统 Windows Forms/.NET 桌面组件。
3. 免 Python 版无需额外运行环境，内置 CPython 3.10.11 x64。
   只有源码版安装、升级需要自行安装 Python 3.10+ 并启用 PATH。
4. 游戏和工具文件夹都需要写入权限。建议预留至少 3 GB，存档和累积备份另算。
5. 不需要 AI 模型、CUDA、Cheat Engine 或额外安装 Lua。

当前只适配 Steam app 4259190 / build 25661788。
原版 EXE SHA-256：
ea9d367b89aa879fc013fdd790be46e44b89b6c4515f29dc4ebddddf2d0340dd
版本不符时安装器会拒绝安装，不要跳过校验。其他平台和游戏版本未适配。

三、文件放哪里
把 ZIP 完整解压到可写文件夹，例如 D:\Tools\KR6-Live-Control\。
不用放进游戏目录，不要直接在 ZIP 内双击运行，也不能只拿走 Launch.cmd。
安装文件、脚本和 systems_wrapper.lua 必须保留在同一文件夹。

四、第一次安装
1. 先确认原游戏可以正常运行，然后正常退出游戏。
2. 在 Steam 库中右键游戏 → 管理 → 浏览本地文件，找到游戏安装位置。
3. 双击工具文件夹里的 KR6-Installer.exe 或 Install.cmd。
4. 选择直接包含 Kingdom Rush Genesis.exe 的那一层文件夹。
   不要选择 Steam 总目录，也不要选择存档文件夹。
5. 等待提示安装完成。

安装器读取并校验本机原版 EXE，在游戏目录生成：
Kingdom Rush Genesis Live V4 Mod.exe
v4.1 仍沿用这个文件名。原版 EXE 保持不变。
工具目录会生成 manifest.json，记录你自己的游戏路径。
工具不扫描全盘、不下载游戏，也不从别人电脑上的路径读取游戏。

五、如何启动并确认生效
1. 建议先打开 Steam。
2. 双击工具目录的 Launch.cmd，打开中文控制面板。
3. 点击“启动新版 MOD”。不要同时运行原版和 MOD。
4. 进入关卡并让游戏继续运行，等待面板显示“已连接”和回传的倍率。
5. 修改数值后点击对应的“应用”按钮，回传值变化才表示已生效。
   只改变输入框里的数字，不代表游戏已经应用。

更新到新 MOD 后需要重新启动游戏一次，之后关卡中调参数不用反复重启。
切出游戏可能自动暂停；若一直等待，请切回并恢复运行。
Steam 普通“开始游戏”通常启动原版，不会自动应用此 MOD。

六、各选项怎么用
英雄经验：1–100 倍，影响之后获得的经验。
主动技能经验：1–100 倍，影响援军、法术等主动技能，独立于英雄经验。
游戏速度：1–5 倍，1 倍正常，建议先试 2 倍。
当前金币：0–999999，一次性设置余额，默认输入为 50000，点击才修改。
击杀金币：0–100 倍，支持两位小数，进入关卡后点击“应用本局倍率”。
  例如原来击杀奖励 10 金币，设 1.5 倍后奖励 15。
  只影响之后击杀，不补发以前的钱；卖塔、提前开波等奖励不放大。
  设 1 恢复正常；设 0 不再获得击杀金币。
  小数金币按游戏原有数值累积，例如 3 × 1.5 = 4.5，画面显示可能取整。
  仅当前局有效，换局、重开或重启游戏恢复 1 倍。

英雄经验倍率、主动技能经验倍率和速度设置会保留到后续使用；
“只对本局生效”专指击杀金币倍率，不是所有选项。
已经获得并保存的经验不会因为关闭工具自动撤销。

七、升级、备份与恢复原版
升级前正常退出游戏，再次双击 KR6-Installer.exe 或 Install.cmd，自动备份旧 MOD 并升级。
独立版也可在工具目录打开终端，执行：
KR6-Installer.exe --game-dir "你的游戏安装目录" --upgrade
源码版对应命令：
python build_mod.py --game-dir "你的游戏安装目录" --upgrade
也可以把 python 换成 py -3。
升级会验证新文件，备份旧 MOD 和安装记录到 mod_backups，再替换 MOD。
命令行首次安装不加 --upgrade；图形入口会自动判断安装或升级。

原版和 MOD 共用存档。安装及通过面板启动 MOD 时会备份现有存档，
备份在工具目录的 save_backups 中；直接双击游戏 EXE 不经过面板启动备份。
存档通常位于 %APPDATA%\kingdom_rush_genesis。
恢复存档时先退出游戏并另存当前存档，注意 Steam Cloud 的同步。
想玩原版，可关闭 MOD 后从面板点“启动原版”或正常通过 Steam 启动。

八、发给别人时发什么
推荐直接分享 Releases 的免 Python ZIP，接收者无需安装 Python。
不要把安装后的文件夹重新打包；直接分享发布的干净 ZIP 即可。
也可以分享源码，但源码版接收者仍需要安装 Python。

不要分享安装后的整个工具文件夹或游戏目录。分享包不要包含：
- 原版 EXE、生成的 MOD EXE、游戏 DLL、游戏资源或提取的原版脚本。
  生成的 MOD EXE 包含游戏本体内容，不是一个独立的小补丁。
- manifest.json：里面是你自己的绝对路径。
- save_backups：你的存档。
- mod_backups：完整旧版 MOD。
- 本机快捷方式、状态文件、配置及临时文件。

源码分享保留原创 .py、.ps1、.cmd、systems_wrapper.lua、README.md、本说明和 LICENSE。
免 Python 包包含可分享的 KR6-Installer.exe、启动脚本、说明和第三方许可证。
KR6-Installer.exe 不含游戏本体，与生成的游戏 MOD EXE 是两种不同文件。
测试脚本可附带，但使用者正常安装和玩游戏不需要运行测试。
原创代码使用 MIT License，分享时保留许可证和署名；原游戏资源不在该许可内。

九、常见问题
找不到 Python：优先改用 Release 免 Python 版；源码版需确认 Python 至少 3.10。
找不到 manifest.json：先在本机安装，不要拿别人的 manifest.json 来替代。
Unsupported game build：当前游戏版本不匹配，需等待重新适配。
一直显示“—”：确认启动新版 MOD、进入关卡、恢复运行，并关闭其他旧面板。
访问被拒绝：检查目录写入权限及游戏是否已退出。
移动游戏后打不开：在新游戏位置重新安装；已有 MOD 时使用 --upgrade。
